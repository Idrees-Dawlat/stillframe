# WordPress.org directory assets

This folder is not loaded by WordPress. Do not copy it into the plugin zip.

Icon and banner files for the plugin directory belong here later:

- `icon-128x128.png`
- `icon-256x256.png`
- `banner-772x250.png`
- `banner-1544x500.png`

Those files are uploaded to the `assets` directory of the WordPress.org SVN repository. They are not part of the plugin that sites install.

This version does not include icon, banner, or screenshot images.
