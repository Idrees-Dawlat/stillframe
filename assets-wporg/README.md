# WordPress.org directory assets

This folder is not loaded by WordPress. Do not copy it into the plugin zip.

Upload these files to the `assets` directory of the WordPress.org SVN repository:

- `icon-128x128.png`
- `icon-256x256.png`
- `banner-772x250.png`
- `banner-1544x500.png`

The icon is a camera inside a frame, in Grafucci teal (`#005976`) on the pale sidebar wash (`#e6f4f8`). The banner uses the same dark teal field as Grafucci Folders: the real capture bar and selection on the left, the icon on the right.

Regenerate both sizes with `_make-banner.ps1`.
