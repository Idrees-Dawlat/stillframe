# Stillframe – Screenshot Capture & Markup for WordPress

Stillframe is a lightweight WordPress plugin that lets administrators capture, annotate, and export screenshots of any admin dashboard screen or front-end page directly inside the browser.

## Features

- **Flexible Capture Modes**: Capture custom drag-selected screen regions, active windows, or full-page views.
- **Viewport Emulation**: Preview and capture pages at standard Mobile (390px), Tablet (834px), or Desktop (1440px) widths.
- **Clean WordPress Mode**: Hide admin bars, navigation menus, or third-party plugin notices for clean showcase screenshots.
- **Built-in Annotation Tools**: Draw freehand sketches, perfect circles, directional arrows (with 45° snapping), and custom color highlights with adjustable line thickness.
- **High-DPI Export**: Save high-resolution PNGs at 1x, 2x, or 3x scale.
- **Save to Media or Download**: Save screenshots directly to your WordPress Media Library or download them to your computer.
- **Automatic File Naming**: Saved screenshots are cleanly named based on the page URL, viewport width, and export scale (e.g. `stillframe-dashboard-1440w-1x.png`).
- **Privacy & Zero Database Footprint**: Operates entirely client-side. Leaves no options, transients, or custom tables in your database, and only loads for logged-in administrators (`manage_options`).

## Installation

1. Upload the `stillframe` folder to `/wp-content/plugins/` or install the ZIP file through **Plugins > Add New Plugin > Upload Plugin**.
2. Activate Stillframe through the Plugins screen.
3. Click the camera icon in the top admin bar or navigate to **Tools > Stillframe** to start capturing.
