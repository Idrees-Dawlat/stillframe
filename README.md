# Stillframe – Screenshot Capture & Markup for WordPress

Stillframe is a lightweight WordPress plugin that lets administrators capture, annotate, and export screenshots of any admin dashboard screen or front-end page directly inside the browser.

## Features

- **Multi-Device Studio (Tools > Stillframe)**: Batch-capture Desktop (1440px), iPad/Tablet (834px), and Mobile Phone (390px) viewports with one click.
- **Target Any Site Page or URL**: Pick from published pages and posts or enter any custom URL.
- **Flexible Capture Modes**: Custom drag-selected screen regions, active windows/elements, or full-page scrolling captures.
- **Pro Annotation Suite (9 Tools)**: Select & Transform (V), Freehand Pen, Circle/Ellipse, Directional Arrow, Rectangle, Highlighter, Resizable & auto-wrapping Text, Numbered Step badges, and Privacy Blur / Pixelate.
- **Advanced Transforms**: Marquee multi-selection, Shift-click, Ctrl+A, move, resize, and rotate annotations.
- **Clean Presentation Mode**: Automatically hide the WordPress admin bar for showcase-ready captures.
- **Retina & High-DPI Export**: Save high-resolution PNGs at 1x, 2x Retina, or 3x Ultra.
- **Save to Media or Download**: Save screenshots directly to your WordPress Media Library with instant preview notifications or download to your machine.
- **Privacy & Zero Database Footprint**: Operates 100% client-side in your browser. Zero database bloat, no external tracking, and strictly restricted to administrators (`manage_options`).

## Installation

1. Upload the `stillframe` folder to `/wp-content/plugins/` or install the ZIP file through **Plugins > Add New Plugin > Upload Plugin**.
2. Activate Stillframe through the Plugins screen.
3. Click the camera icon in the top admin bar or navigate to **Tools > Stillframe** to start capturing.
